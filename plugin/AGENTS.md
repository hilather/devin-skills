# Devin Skills (workflow pointers)

Plugin install of ~/git/devin-skills/. Commands are `/devin-skills:design` unless you also ran `install.sh` (then `/design`).

- Specs: /design (writer/reviewer loop). Mandatory PR Plan and Key Decisions. Does not implement.
- Implementation planning: Devin's builtin /plan. Do not create a skill named plan.
- After the plan is approved, implement. There is no write-lock.
